# hiroebe.net

Personal blog built with [Astro](https://astro.build/), hosted on [GitHub Pages](https://pages.github.com/).

https://hiroebe.net

## Commands

| Command        | Action                                       |
| :------------- | :------------------------------------------- |
| `pnpm install` | Install dependencies                         |
| `pnpm dev`     | Start local dev server at `localhost:4321`    |
| `pnpm build`   | Build production site to `./dist/`           |
| `pnpm preview` | Preview build locally before deploying       |

## Credit

Based on the [Astro Blog](https://github.com/withastro/astro/tree/main/examples/blog) starter template, styled after [Bear Blog](https://github.com/HermanMartinus/bearblog/).
